# ZIP Архиватор (C# / .NET 10)

Настольное и консольное приложение для просмотра содержимого, создания и распаковки ZIP-архивов.

## Структура репозитория

- `Archiver.Core/` — библиотека классов с основной бизнес-логикой (модели, интерфейсы, базовый класс, сервис работы с ZIP, сохранение состояния в JSON).
- `Archiver.WinForms/` — графический интерфейс (Windows Forms) и обработчик параметров командной строки.
- `demo.ipynb` — Jupyter Notebook с примерами запуска и тестирования через командную строку.

## Основные возможности

- Просмотр списка файлов внутри `.zip` архива (имя, путь, исходный и сжатый размер, процент сжатия).
- Упаковка файлов и папок в `.zip` с выбором режима сжатия (`Optimal`, `Fastest`, `NoCompression`).
- Распаковка архивов в выбранную директорию с отображением прогресса.
- Сохранение и загрузка состояния программы (настройки, тема оформления, очередь файлов) в `state.json`.
- Горячие клавиши (`F1` — справка, `Ctrl+O` — открыть, `Ctrl+N` — создать, `Ctrl+E` — распаковать, `Ctrl+S` — сохранить состояние) и Drag & Drop.
